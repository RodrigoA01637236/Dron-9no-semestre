# Bitácora de vuelos y visitas de campo

Una entrada `AAAA-MM-DD.md` por cada vuelo, visita de campo o sesión de pruebas relevante: lugar, condiciones, qué se hizo, resultados, fallos e incidentes, datos recolectados y a dónde se respaldaron.

La bitácora alimenta: el análisis de fallos (doc 09), el registro de incidentes de seguridad (doc 10) y las cifras del pitch (doc 11 — toda cifra comercial debe rastrearse a una entrada de aquí).
