Modelo

Cada foto que revisas le enseña al modelo. Cuando juntes varias correcciones, reentrénalo aquí. El modelo nuevo se compara con el actual en un examen de campo (fotos revisadas que nunca se usan para entrenar) y una persona decide si se activa.

Las revisadas en campo entran al entrenamiento. Las del examen de campo, alrededor del 20 %, nunca se entrenan: sirven para medir si el modelo mejoró de verdad.

Reentrenar

La computadora debe quedarse encendida con esta ventana abierta. Puedes seguir revisando fotos mientras entrena.
